# 华火新能源电火灶项目系统测试填写稿

## 1. 新建项目

项目名称：
华火新能源电火灶诊断测试

## 2. 对话入口第一轮建议输入

我们现在想诊断一个华火新能源电火灶区域代理项目。华火是等离子电生明火电火灶品牌，产品有纯电明火、安全、节能、国标参与和专利背书，但终端认知很低、价格高、线上转化弱。核心接触方卢老板持有上海浦东、厦门同安/翔安、天津等区域代理权，目前厦门有3个直播间和6人团队，上海浦东和天津几乎零人员、零门店、零推进。视频号出过百万播放，但成交主要靠熟人介绍，只有十几台到几十台规模。总部严格控价，代理商不能低价清库存，但要承担区域售后。现在库存难变现、现金流紧张，想在30天内判断应该先打哪个战场，并形成可执行的市场验证和成交闭环。

## 3. 问题地图应确认的信息

公司名称：
华火新能源电火灶项目（卢老板区域代理）

行业：
新兴厨电 / 电火灶 / 区域代理分销

主营业务：
代理销售华火等离子电生明火电火灶，覆盖家用单灶、双灶、集成灶及商用大功率灶。

商业模式：
区域代理 + 线上内容引流 + 熟人转介绍 + 总部统一控价和区域售后返佣。

规模：
代理商厦门3个直播间、6人团队；持有上海浦东、厦门同安/翔安、天津等区域代理权；母公司约40人，注册资本3000万、实缴990万。

发展阶段：
品类早期教育期 / 代理商试错期 / To B 招商驱动期

核心问题：
产品概念和政策顺风很强，但终端认知低、线上转化弱、代理商核心区域没有启动，库存和现金流压力较大。

目标：
30天内明确从0到1的市场验证路径：先选定高潜客群和试点场景，跑出可复用的获客-成交-售后闭环，并决定浦东/天津代理权是否继续投入。

约束：
总部全国控价，代理商没有自主降价权；线下前期投入意愿低；售后必须本地承接但维修能力不足；大厂可能2-3年内切入。

成功标准：
形成1个可复用试点场景、3类高意向客群画像、10个有效体验/成交线索、首批成交或预订、售后响应SOP和预算红线。

建议优先诊断：
市场与客户

## 4. 方案选择建议

如果系统生成 A/B 两套问卷：
优先选择“方案 A · 全面覆盖”。

原因：
这个项目不是单一投放问题，而是市场教育、产品信任、销售转化、区域渠道、售后运营、组织执行和现金约束叠加，全面覆盖更适合压测系统。

## 5. 市场与客户模块

公司名称：
华火新能源电火灶项目（卢老板区域代理）

主营产品/服务：
等离子电生明火电火灶，家用单灶/双灶/集成灶/商用10000W大功率灶。

目标用户群：
高端尝鲜家庭、别墅/改善型厨房、禁燃商办会所、民宿和商用厨房；代理区域为上海浦东、厦门同安/翔安、天津。

主要产品定价：
家用主力款约2000-5500元，商用产品可达数万元；竞品星焰大促价约2017元，焱龙约1599元。

主要竞品：
星焰STARFIRE、焱龙、传统燃气灶品牌、成熟电磁/电陶炉，以及潜在美的/老板/方太等大厂。

估计市场份额：
华火线上授权/官方店同质化分流，单SKU付款数多为4-21人，旗舰款有100+付款；星焰爆款1000+付款。

补充说明：
全球电焰灶/电火灶市场约47-50亿元，预计2031年接近10亿美元，CAGR约5.7%-6.1%。双碳、禁气和老旧改造带来政策红利，但品类仍处于早期教育阶段。华火的问题不是没有概念，而是高客单价和低认知之间错位，线上店群同质化、价格内卷、卖点偏技术参数，缺少面向消费者的大白话钩子。

痛点勾选：
打不过竞品；找不到精准客户；客户在流失

## 6. 产品与服务模块

核心产品：
华火等离子电生明火电火灶，纯电驱动产生1200-1300摄氏度开放式物理明火。

产品原材料/构成：
等离子放电炉头、脉冲与特殊等离子技术、家用/商用灶具结构；厨房高油烟高热环境对核心部件耐久性要求高。

研发投入占比：
未披露；母公司定位重研发轻资产，约40人团队，300+知识产权、172+发明专利、23+国际专利。

迭代周期：
未披露；已有U7 Pro、U9、U10 Pro、商用10000W等产品矩阵。

产品差异化卖点：
纯电安全、物理明火、不消耗氧气、不产生CO/SO2、热效率78.4%-81.5%、不限锅具、参与电火灶节能认证技术规范制定。

补充说明：
用户搜索联想包含“是不是骗局”。消费者对用电召火安全性、电磁辐射、零部件老化和售后可靠性有疑虑。产品技术很强，但终端语言偏“黑科技”和参数展示，需要转成安全、好用、省钱、适合禁燃场景的信任表达。

痛点勾选：
客户用不起来；产品同质化

## 7. 营销与销售模块

主要获客渠道：
微信视频号内容、央视采访片段转发、熟人朋友介绍、线下家具节/购物节、寄售门店；目前无成熟线上店铺和系统投放。

获客成本：
未量化；线下活动投入高、效果差，视频号有百万播放但成交低。

转化率：
未有完整漏斗；报告描述客单转化率低，累计销量主要来自熟人介绍，约十几台到几十台。

客单价：
家用约2000-5500元，区域返佣约10%，单台约200-500元。

销售团队规模：
厦门3个直播间、6人团队；上海浦东和天津核心区域零人员、零门店、零推进。

上季度营收：
未披露；库存资产无法变现，现金流吃紧。

补充说明：
总部统一控价，代理商几乎无自主降价和清库存权限，擅自低价可能被批评或撤销代理权。销售不是简单多发视频，而是要建立“谁会买、为什么现在买、在哪里体验、如何成交、售后谁负责”的闭环。

痛点勾选：
转化率低；销售周期太长；过度依赖单一渠道

## 8. 运营与供应链模块

平均交付周期：
未披露；总部发货和售后模式为寄回深圳总部维修，期间提供样机顶替。

主要成本构成：
代理库存占压、直播间人力、内容制作、线下活动、物流、售后维修和样机周转。

产能利用率：
母公司宣称有国内6个、国际4个生产基地，但终端消费拉动不足。

供应商数量：
未披露；母公司宣称联动1500+上下游企业，但多为招商节点而非稳定终端触点。

库存周转：
库存资产无法变现，具体金额和周转天数缺失。

补充说明：
区域下单由本地代理承接售后责任，返佣约10%。本地维修能力薄弱，批量故障可能造成物流成本、样机周转压力和用户投诉风险。售后体系如果没有先建好，会吞掉代理利润。

痛点勾选：
成本过高；供应链不稳定；交付太慢

## 9. 组织与人才模块

员工总数：
代理商厦门团队约6人；上海浦东/天津区域无团队。母公司约40人。

组织架构：
卢老板主导，厦门直播间团队与当地代理商私交混编测试；缺少区域负责人、售后负责人、投放/数据负责人。

人均产值：
未披露；当前销量低，组织产出不足。

核心岗位空缺：
浦东/天津市场启动负责人、渠道BD、体验点/样板客户负责人、售后服务负责人、投放和数据分析负责人。

年度流失率：
未披露。

补充说明：
卢老板表达发散、有热情和想象力，但执行闭环弱；对重资产和线下渠道投入高度排斥。曾提出发动1000个宝妈直播，但目前缺少机制设计、培训、激励和转化承接。

痛点勾选：
缺关键人才；人效低

## 10. 财务与资本模块

上年度营收：
代理商未披露；销量约十几台至几十台为主，库存难变现。母公司财务未披露。

毛利率：
区域返佣约10%，单台约200-500元；扣除售后、物流、人员和运营成本后利润空间很薄。

净利率：
未披露，存在售后泥潭吃掉利润的风险。

现金流状况：
库存资产无法变现，现金流吃紧，具体现金余额/月固定支出缺失。

负债率：
未披露。

融资轮次：
代理商无融资信息；母公司注册资本3000万元，实缴990万元。

补充说明：
如果持续把市场教育成本压给代理商，但又没有成交闭环，现金会被库存、售后、线下试错和内容团队持续消耗。30天内必须设定预算红线和停止条件。

痛点勾选：
现金流紧张；不盈利

## 11. 期望诊断结果检查点

提交后重点检查：
1. 是否调用多个专家，而不是只给市场泛泛建议。
2. 作战室主战场是否大概率落在“市场与客户”，次战场可能是“产品与服务”或“销售与增长”。
3. 是否要求补齐推广账号、投放报表、视频号后台、CRM漏斗、库存金额、现金流和售后工单。
4. 部门动作是否能拆到市场、产品、销售、运营、组织、财务，而不是只有“多做营销”。
5. 项目工作台是否只有一个“项目作战室”，诊断记录只是“查看记录”。
