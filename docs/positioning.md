# 产品定位说明 v1

- 日期：2026-06-16
- 用途：对内统一认知、对外讲清"我是什么"。一页讲完，不堆术语。

---

## 一句话定位

**老板的 AI 经营参谋**——以"一个项目（一家企业）"为单位，持续建档、反复诊断、给可执行的咨询动作、并追踪复盘效果。

不是工具，不是聊天助手，是**一个会陪着这家企业一起走的外部参谋**。

---

## 我们是什么 / 不是什么（关键边界）

| | ❌ 不是 | ✅ 是 |
|---|---|---|
| 形态 | SaaS + 一堆 Agent 功能（有赞/微盟那类） | 独立、跨行业的诊断与陪跑系统 |
| 记忆单位 | 围绕"功能操作"的一次次任务 | 围绕"项目"的持续企业长期档案 |
| 输出 | 帮你把系统操作得更快 | 给老板"先打哪场仗、谁先动、怎么追结果" |
| 咨询 | 话术上叫"顾问"，底下没方法论 | 诊断能力 skill + 行业基准 + 案例飞轮 + 真人审核 |
| 绑定 | 锁死在某个电商/ERP 生态 | 不依赖任何 SaaS 生态，谁都能用 |

**一句话区分：他们做的是"懂系统的助手"，我们做的是"懂经营的参谋"。**

## 我们站在市场的哪个空位

```
工具型（微盟/有赞/用友）        本产品（空白区）            纯人力咨询
──────────────────────┼──────────────────────┼─────────────────────
帮你"操作"业务系统       给老板"诊断+参谋"持续档案     麦肯锡/本地咨询公司
有 Agent 但无诊断        有方法论+沉淀+人审           贵、慢、不可复制、不留存
```

- **左边**：能执行，但不懂诊断——它假设你已经知道要干嘛。
- **右边**：懂诊断，但贵、慢、不留存、不可规模化。
- **我们**：把右边的"诊断能力 + 持续陪跑"，用 AI 做成左边的"付得起、当天能用"。

这个中间地带目前几乎无人占住。

---

## 对老板的核心承诺

1. **看过你的真实经营数据后，告诉你问题真正卡在哪**——不是泛泛而谈，是结合你上传的数据 + 行业基准做内外对比。
2. **给的是动作，不是空话**——结论落到"先动哪几件事、谁负责、怎么验收"。
3. **有人把关，不是 AI 一锤定音**——诊断先过机器考试，再由真顾问审核签字才交付。
4. **越用越懂你**——每次诊断沉淀进企业档案，复诊不用重说，系统记得这家企业的来龙去脉。

---

## 最大软肋（必须正视）

**诊断到结果，隔了一层。**

- 有赞的 Agent 直接动 GMV（卖货、设活动），老板立刻看到钱。
- 我们的诊断隔一层——给的是"判断 + 动作"，老板执行后才见效。

市场数据印证这个风险：43% 的企业 CIO 已对"AI 宣传疲劳"、要求可量化 ROI 才续约；46% 中国企业在用生成式 AI，但只有 9% 真见到效益。

**老板最终问的永远是："这帮我多赚了多少 / 少亏了多少？"**

### 怎么打通这一层（产品命脉）

把"诊断"接到"老板看得见的经营结果"上：

1. **复盘追踪量化**（Loop 3 案例飞轮已有数据位）：7/14/30 天回访，记录"采纳了哪些建议 → KPI 改善了多少"，把效果显性化。
2. **按效果付费试点**（2026 风口）：当能证明"采纳建议后改善了 X"，可从订阅制转向价值分成——客户愿为确定结果付费，不为可能性功能买单。
3. **每个交付物自带验收标准**：作战室动作卡必须带"两周后看什么指标"，让老板自己能验证有没有用。

## 护城河（为什么别人难抄）

国际（SaaSpocalypse 后的共识）和国内（微盟 Know-how 论）指向同一句：

> **护城河不在代码，在数据沉淀 + 隐性业务逻辑 + 服务积累。**

我们在攒的三样：
- **诊断能力 skill 库**：按"诊断能力"组织、跨行业通用、过考试才上线。
- **案例飞轮**：每个真实项目脱敏沉淀，客户越多系统越懂行业。
- **行业基准知识库**：抓取即沉淀，越用越厚。

代码能抄，这三样攒出来的深度抄不走——**前提是真客户跑起来，飞轮才转。**

## 一句话收尾

**用 AI 把顶级咨询的诊断能力，做成老板付得起、当天能用、给的是动作不是空话的系统。**

竞争不在"谁的 Agent 多"，在"谁能把诊断真正接到老板的经营结果上"。
